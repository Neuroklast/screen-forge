## Business flows

### Film & TV

**Director builds and runs a show** (`flow-show-build`)
1. Open the sequence editor.
2. Add or load steps (palette drag or show template).
3. Set trigger (time/key/pin/signal), `next`/`onFail` branch, timeout.
4. Run the show (advance/fail/timeout walk the branches).
5. Record the take (ok/fail/timeout) and export JSON/CSV.

**Design a scene look** (`flow-scene-design`)
1. Choose a functional scene (`intranet`, `os`, `terminal`, `countdown`, `tracking`, `hologram`, …).
2. Apply identity (company profile) and theme (palette/accent/font).
3. Tune mood, density, effects, overlays, media, stage format and frame.

### Training / exercise control

**EXCON builds a mission** (`flow-mission-build`)
1. Create from the guided wizard or a mission template.
2. Assemble stations and entities (props/patients/teams/actors/zones) on the board.
3. Bind props and patients to stations.
4. Configure injects (MEL: trigger + actions).
5. Lint (errors block start) and save (revision bump; stale saves rejected).

**Provision field devices** (`flow-device-provision`)
1. Issue a one-time QR invite for a station.
2. Device redeems the invite over `/exercise` and receives a credential.
3. Check readiness/presence.
4. Release the start gate (`play` rejected while the linter reports errors).

**Run and steer the exercise** (`flow-exercise-run`)
1. Start / pause / reset (phase transitions; reset restores the baseline).
2. Fire and reschedule MEL injects (journaled with actor + reason).
3. Change patient state / interventions.
4. Release dossiers, cut/restore camera signals, send messages.
5. Debrief from the event log + MEL timeline (CSV/JSON export).

**Safety abort** (`flow-safety-abort`)
1. Reach abort in ≤ 2 taps (EXCON + safety console).
2. Independent authority — works without EXCON confirmation.
3. Banner reaches every device within one tick; log records role + time.

### Interaction engine

**Player solves a field task** (`flow-player-task`)
1. The field shell mutates into the active task surface (full-screen, no scroll stack).
2. Shared capabilities collect input (CodeEntry, Dial, CodeTable, DataSheet, Timer, …).
3. Input becomes an `interaction` command; the interpreter decides the output port.
4. Journaled `workflow.*` events are projected per role with secrets blanked.

**Vertical pilot: link → code → diagnostics** (`flow-workflow-pilot`)
1. A prop state change starts the workflow and shows the link surface.
2. `code-entry` compares against a secret variable; wrong input increments the counter.
3. At `maxAttempts` the failure edge leads to the lockout surface.
4. Success shows diagnostics and completes the objective.

### Runtime & durability

**Durable command/event round-trip** (`flow-durability`)
1. Command envelope (`eventId`/`deviceId`/`deviceSeq`) persisted to IndexedDB.
2. Server validates, ACKs, applies a domain event.
3. Event appends to the per-room journal (`serverSeq`).
4. Restart replays the journal; state is projected per role before broadcast.

### Demo

**Offline demo tour** (`flow-demo-tour`)
1. `/?demo=1` routes to the offline shell; no `/exercise` socket is opened.
2. `tour.json` drives seven stops: film, build, field, HQ, injects, debrief, sandbox.
3. Sandbox edits live in memory; reset restores the seeded show and mission exactly.
4. Kiosk mode restarts the tour after 90 s idle and exits with the presenter PIN.

### Platform

**Quality gate before done** (`flow-quality-gate`)
1. Static checks: `tsc --noEmit`, i18n guard, layout contract guard.
2. Tests: vitest core/map + node server tests + Playwright E2E.
3. Production Vite build (PWA plugin).
